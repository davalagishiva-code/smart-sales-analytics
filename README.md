# Smart Sales Analytics & Prediction System

Project scaffold for the Smart Sales Analytics & Prediction System. Follow the README as we build the project step-by-step.

## 🎨 New Feature: Professional Theme System (v2.0)

The dashboard now includes a complete theme customization system with 5 professional themes and extensive settings options.

### Quick Start with Themes
1. Run the Flask app: `python app.py`
2. Click **⚙️ Settings** in the sidebar
3. Select your preferred theme from the visual preview cards
4. Customize layout, font size, sidebar, and notifications
5. All settings save automatically to localStorage

### Available Themes
- 🌟 **Light** - Professional blue (default)
- 🌙 **Black** - Dark mode with blue accents
- ⚫ **Grey** - Neutral monochromatic
- ⚪ **White** - Pure white high contrast
- ⬜ **Black & White** - Maximum accessibility

### Settings Features
- **🎨 Theme Selection** - Live preview cards with instant switching
- **📐 Layout Options** - Comfortable or Compact density
- **☰ Sidebar Toggle** - Collapsible sidebar
- **🔤 Font Size** - Small, Medium, or Large
- **🔔 Notifications** - Enable/disable alerts
- **💾 Save/Reset** - Persistent storage or restore defaults
