About Smart Sales Analytics

This project demonstrates data cleaning, analysis, visualization, and a basic sales prediction model using Python, Pandas, Scikit-learn, and Flask.

Features

  • Data cleaning and ETL with Pandas
  • Relational storage in MySQL (schema and sample scripts)
  • Exploratory analysis and visualizations (Matplotlib / Seaborn)
  • Basic machine learning model for sales prediction (RandomForest)
  • Flask web dashboard with prediction endpoint
