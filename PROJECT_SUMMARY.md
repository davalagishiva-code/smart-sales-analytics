🚀 GETTING STARTED

1. LAUNCH THE APPLICATION
   python app.py
   
   (Navigate to http://localhost:5000 in your browser)

2. NAVIGATE TO SETTINGS
   • Click ⚙️ Settings in the sidebar

3. EXPLORE THEMES
   • See all 5 theme preview cards with color swatches
   • Click any theme to instantly apply it

4. CUSTOMIZE YOUR EXPERIENCE
   • Choose layout density (Comfortable/Compact)
   • Toggle sidebar collapse if needed
   • Adjust font size to your preference
   • Enable/disable notifications

5. YOUR SETTINGS ARE SAVED
   • All changes save automatically
   • Settings persist across browser sessions
   • No manual save button required
   • (Optional save button for confirmation)
